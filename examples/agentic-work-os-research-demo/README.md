# Agentic Work OS Research Demo

## Purpose

This fictional demo teaches the concept of Agentic-Work-OS while using the system.

The user gives the agent short research notes about AI collaboration systems. The agent creates a simple reference card explaining what Agentic-Work-OS is and why file-based state helps multiple agents collaborate.

## How To Run

Ask your agent:

```text
Read AGENTS.md and System/Core. Then run examples/agentic-work-os-research-demo using sample-research-notes.md. Create a short reference card that explains Agentic-Work-OS to a new user.
```

## What The Agent Should Do

1. Read `sample-research-notes.md`.
2. Extract the core ideas.
3. Produce a reference card similar to `expected-reference-card.md`.
4. Explain how the demo itself shows routing, synthesis, output, and handoff.

## Fictional Boundary

All notes are invented for this demo. They are not copied from a private system or real research report.
