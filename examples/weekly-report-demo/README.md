# Weekly Report Demo

## Purpose

This fictional demo shows how Agentic-Work-OS turns scattered notes into a structured output while leaving enough context for another agent to continue.

## How To Run

Ask your agent:

```text
Read AGENTS.md and System/Core. Then run examples/weekly-report-demo using sample-input.md. Create a weekly report, explain where the output should go, and record what should be added to a project work log.
```

## What The Agent Should Do

1. Read `sample-input.md`.
2. Identify the goal: create a weekly report.
3. Produce a structured weekly report similar to `expected-output.md`.
4. Explain that the final output belongs in `output/`.
5. Suggest a short project log entry so another agent can continue later.

## Fictional Scenario

The user is preparing a weekly personal work summary for a fictional product experiment called "Northstar Notes". This demo does not represent a real company or project.
