# Maintainer Notes

## What Was Published

This repository is the public v0.1 starter for Agentic-Work-OS.

It includes:

- public README and Chinese README;
- `AGENTS.md` as the single source of agent behavior;
- public-safe `System/Core` templates;
- active project, skills, resources, and system log templates;
- two fictional demos;
- safety, compatibility, roadmap, and introduction docs;
- MIT license and community files.

## What Was Not Published

This repository does not include:

- a private workspace export;
- personal profiles;
- real current state;
- real active project worklogs;
- real business workflows;
- full teaching sandbox;
- private source assets;
- credentials or secrets.

## How This Repository Was Uploaded

The repository was created as an empty public GitHub repository under `lishuyang0422-tech/Agentic-Work-OS`.

Local HTTPS push returned a 403 credential error, so the initial public files were uploaded through the GitHub connector contents API.

Because of that upload method, the initial history contains multiple file-level commits instead of one single local initial commit.

## How Future Agents Should Maintain It

1. Read `README.md`.
2. Read `AGENTS.md`.
3. Read `docs/roadmap.md`.
4. Confirm that any new example is fictional.
5. Do not copy private workspace files into this repository.
6. Prefer pull requests or reviewed local commits for future changes.
