# Roadmap

## v0.1 Starter

Goal: publish a small, safe, understandable starter.

Includes:

- local-first workspace skeleton
- `AGENTS.md`
- public-safe `System/Core` templates
- two fictional demos
- safety docs
- basic contribution docs

## v0.2 More Fictional Demos

Upgrade condition:

- users complete the first demos
- feedback shows what remains confusing
- new demos can stay fully fictional

Possible additions:

- personal planning demo
- public reading synthesis demo
- small project handoff demo

## v0.3 Workflow Templates

Upgrade condition:

- users ask how to design their own repeatable workflows
- the template format is stable
- no private workflow logic is needed

Possible additions:

- richer workflow template
- project review template
- handoff checklist

## v0.5 Release Tooling

Upgrade condition:

- the release manifest has survived multiple versions
- safety checks are stable
- automation can reduce mistakes without hiding risk

Possible additions:

- release preparation script
- sensitive-term scan
- hidden-file scan
- manifest validator

## v0.7 Agent Compatibility

Upgrade condition:

- community members request specific setup notes
- compatibility docs can remain lightweight
- `AGENTS.md` stays the single source of truth

Possible additions:

- tool setup notes
- prompt snippets
- community-maintained compatibility table

## v1.0 Stable

Upgrade condition:

- core structure has stabilized
- demos have been tested by multiple users
- repeated issues have been addressed
- contribution and safety flows are clear

Possible additions:

- tagged stable release
- stronger examples
- community case studies

## Companion Sandbox

A larger teaching sandbox may be considered only if:

- it is rewritten from scratch with fictional data
- it passes privacy review
- there is strong user demand
- maintainers can support it

It should be a companion package, not part of the first small starter release.
