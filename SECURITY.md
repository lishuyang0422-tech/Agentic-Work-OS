# Security Policy

## Public Starter Only

This repository is a public starter template. Do not store private or confidential information here.

Do not add:

- API keys, tokens, passwords, or credentials
- customer data
- personal profiles
- private company documents
- financial records
- confidential project notes
- proprietary workflows

## Reporting Security Issues

If you find a security issue in the public starter template, open a private security advisory if the hosting platform supports it. If not, contact the maintainer through the project's published contact channel.

## Before Publishing Your Own Fork

Run a manual review for:

- secrets
- hidden files
- temporary files
- private names
- internal paths
- confidential examples

Treat examples as fictional unless explicitly documented otherwise.
