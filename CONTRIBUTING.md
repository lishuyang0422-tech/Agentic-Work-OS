# Contributing

Thank you for helping improve Agentic-Work-OS.

Good contributions include:

- clearer documentation
- safer starter templates
- fictional demos that teach the workflow
- typo fixes
- compatibility notes for different AI agent tools
- safety checklist improvements

Please avoid:

- adding private data
- adding real company workflows
- adding tool-specific rules that duplicate `AGENTS.md`
- making the starter harder to understand for new users

## Contribution Principles

1. Keep the starter local-first.
2. Keep the first-run experience simple.
3. Prefer fictional examples.
4. Treat `AGENTS.md` as the single source of agent behavior.
5. Document any new file's purpose.
